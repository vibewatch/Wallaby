# Graby site configs

This package contains the host-specific extraction rules consumed by `@wallaby/graby`. The data is mirrored from [`j0k3r/graby-site-config`](https://github.com/j0k3r/graby-site-config), which in turn synchronizes FiveFilters' site configuration collection.

The config corpus is declared CC0-1.0 by its upstream Composer package. See `SOURCE.md` for the exact snapshot used here.
